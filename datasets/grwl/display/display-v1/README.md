# GRWL display correction

Allen and Pavelsky (2018), GRWL summary V01.02; CC BY 4.0

Versioned PMTiles for the unchanged summary-v01.02-local-r1 analytical release. Explicit display-only dateline splitting prevents a 523 m dateline crossing in source row 28938 from rendering across the world. Source row 13164 retains its upstream 31.28 km straight segment. Use the original GeoParquet for exact geometry and all attributes.

All source IDs and selected tile fields are checked against the source. Independent sampled geometry, antimeridian regressions, native archive verification and local browser reads are recorded in reports/. This package has not been uploaded or independently rebuilt twice.
