# Package instructions

Dataset `grwl-raw`, release `raw-v01.01-local-r1`. Use only the analytic GeoParquet assets `assets/grwl-raw-observations.parquet` for analysis. Preserve source identifiers, values, nulls, geometry, CRS, and feature multiplicity. Field dictionaries are in `metadata/`. This is a local package, not evidence of public hosting or registry acceptance. Keep `manifest.json`, `dataset.yaml`, source attribution, licenses, workflow hashes, and validation reports together.
