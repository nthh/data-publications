# Package instructions

Dataset `hydrolakes`, release `v1-local-r3`. Use only the analytic GeoParquet assets `assets/hydrolakes-polygons.parquet` for analysis. Preserve source identifiers, values, nulls, geometry, CRS, and feature multiplicity. Field dictionaries are in `metadata/`. This is a local package, not evidence of public hosting or registry acceptance. Keep `manifest.json`, `dataset.yaml`, source attribution, licenses, workflow hashes, and validation reports together.
